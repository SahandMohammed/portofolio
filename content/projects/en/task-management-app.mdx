Modern distributed teams need a workspace that feels instantaneous regardless of network conditions. This cross-platform application was engineered with **Flutter** and **Dart**, utilizing an offline-first synchronization engine powered by **Firebase Firestore** and local SQLite caching.

![Real-time synchronization metrics and collaborative board telemetry](/images/projects/system-metrics.svg)

## Offline-First State Architecture

Instead of blocking UI interactions on network round-trips, every board mutation—moving cards, assigning teammates, or updating sprint milestones—applies optimistically to a local state store and queues background sync operations.

<Callout title="Key Result">
  Zero perceived latency on drag-and-drop Kanban interactions with automatic conflict resolution when devices reconnect.
</Callout>

## Optimistic Sync Engine

```dart
class BoardSyncRepository {
  final FirebaseFirestore _firestore;
  final LocalTaskDao _localDao;

  Future<void> moveTaskCard({
    required String taskId,
    required String targetColumnId,
    required double newOrderIndex,
  }) async {
    // 1. Apply optimistic local mutation immediately
    await _localDao.updateTaskPosition(taskId, targetColumnId, newOrderIndex);

    // 2. Queue atomic Firestore batch write
    await _firestore.collection('tasks').doc(taskId).update({
      'columnId': targetColumnId,
      'orderIndex': newOrderIndex,
      'updatedAt': FieldValue.serverTimestamp(),
    });
  }
}
```

## Core Features

- **60fps Custom Kanban Board**: Built with custom Flutter render objects for fluid multi-column drag-and-drop physics.
- **Granular Role Permissions**: Workspace-level and board-level RBAC enforced via Firebase Security Rules.
- **Push Notification Digest**: Intelligent Cloud Functions that batch task updates to prevent notification fatigue.
