Healthcare systems demand uncompromising data integrity, auditability, and security. The Healthcare Portal unifies patient appointment scheduling, encrypted electronic health records (EHR), and clinician workflows into a cohesive platform built with **React**, **ASP.NET Core**, and **Docker**.

![Containerized ASP.NET Core and React architecture for medical records](/images/projects/ecommerce-architecture.svg)

## Security & Audit Architecture

Every access to sensitive patient records is authenticated via short-lived JWTs with rotating refresh tokens and logged into an immutable audit trail.

<Callout title="Security Standard">
  End-to-end field-level encryption (AES-256-GCM) for sensitive patient diagnostic records at rest and TLS 1.3 in transit.
</Callout>

## Appointment Slot Concurrency Control

To prevent double-booking across clinics, the scheduling engine uses distributed locks and database constraints:

```csharp
[ApiController]
[Route("api/appointments")]
public class AppointmentBookingService
{
    private readonly AppDbContext _context;

    public async Task<AppointmentResponse> BookSlotAsync(BookingRequest request)
    {
        await using var transaction = await _context.Database.BeginTransactionAsync(IsolationLevel.Serializable);

        var slot = await _context.ScheduleSlots
            .FromSqlInterpolated($"SELECT * FROM ScheduleSlots WHERE Id = {request.SlotId} FOR UPDATE")
            .FirstOrDefaultAsync();

        if (slot == null || !slot.IsAvailable)
        {
            throw new InvalidOperationException("Selected time slot is no longer available.");
        }

        slot.MarkAsBooked(request.PatientId);
        await _context.SaveChangesAsync();
        await transaction.CommitAsync();

        return slot.ToResponse();
    }
}
```
